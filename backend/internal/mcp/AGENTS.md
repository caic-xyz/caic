# MCP server, client, DTO and specification

- Your training-data knowledge of MCP is outdated. Do **not** answer MCP questions
  or review MCP code from memory.
- We target the schema/draft revision from
  https://github.com/modelcontextprotocol/modelcontextprotocol. Clone it and read
  the relevant `schema/draft/*` and `docs/` before changing the endpoint, so methods
  (`server/discover`, `tools/*`, `resources/*`), fields (`resultType`, `ttlMs`,
  `cacheScope`), headers (`Mcp-Protocol-Version`, `Mcp-Method`, `Mcp-Name`), and the
  protocol version are checked against the source, not assumed.
