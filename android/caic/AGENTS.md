# caic Android App

Native Kotlin/Compose companion app for caic, package `com.fghbuild.caic`.
It manages coding-agent tasks through screen UI, Android notifications, Halo
integration, and the voice path.

Read `../AGENTS.md` first for shared Android rules.

## Architecture

```text
Compose screens -> ViewModels -> Repositories -> SDK ApiClient
                                      -> Gemini/voice gateway transport
                                      -> DataStore settings
                                      -> Halo BLE/message SDK
```

- Hilt owns app dependency injection.
- `TaskRepository` owns the global task SSE connection and per-task streams.
- `SettingsRepository` owns persisted server, auth, and voice settings.
- Voice code lives under `voice/`; Halo app integration lives under `halo/`.
- Screen UI must match the web frontend behavior in `../../frontend/src/`.

## Current State

## Conventions

- Package: `com.fghbuild.caic`.
- DI: Hilt.
- Navigation: Compose Navigation with typed routes.
- Networking: generated `:caic-sdk` and `:voicegateway-sdk` API clients plus OkHttp/SSE/WebSocket where needed.
- Compose UI should be presentation logic only.

- Keep event grouping and turn splitting in sync with `../../frontend/src/grouping.ts`.
- Keep voice function declarations in sync with the web voice implementation.

## Voice Path

Android calls caic backend voice endpoints, then connects through the selected
voice transport. The current checked-in voice path uses WebRTC through the caic
backend bridge; older Gemini Live WebSocket notes remain useful when touching
protocol compatibility.

Token-mode behavior:

| Mode | `ephemeral` | Token source | WebSocket endpoint | Auth param |
|------|-------------|--------------|-------------------|------------|
| Raw key | `false` | `GEMINI_API_KEY` directly | `v1beta.GenerativeService.BidiGenerateContent` | `?key=` |
| Ephemeral | `true` | `POST /v1alpha/auth_tokens` | `v1alpha.GenerativeService.BidiGenerateContentConstrained` | `?access_token=` |

Notes:
- The raw key path uses v1beta and produces higher-quality voice responses.
- Ephemeral token creation is v1alpha only; using v1beta for `auth_tokens`
  returns 404.
- Audio playback must use `USAGE_MEDIA`; `VOICE_COMMUNICATION` clips early audio.
- Client protocol must wait for setup completion before sending media or tools.

## E2E Testing

Android e2e tests mirror frontend Playwright coverage and run against the fake
backend.

- Test runner: `HiltTestRunner`.
- Base class: `e2e/E2eTestBase.kt`.
- All `MainActivity` instrumented tests need `@HiltAndroidTest` and
  `HiltAndroidRule(order = 0)`.
- The fake backend URL comes from instrumentation arg `baseUrl`.
- Screenshots are pulled to `e2e/screenshots/android/`.

Preferred command:

```bash
python3 scripts/android_e2e.py --module caic
```

Run all Android modules with:

```bash
make android-e2e
```

## Checks

For caic app changes:

```bash
make android-check
```

To build, install, and launch the caic app on connected devices:

```bash
make android-push
```

Use `make android-e2e` or `python3 scripts/android_e2e.py --module caic` when
screen behavior, notifications, auth, screenshots, or lifecycle behavior can
regress.
