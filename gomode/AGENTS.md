# Go Mode Server Library

Reusable server-side library for Go Mode hosts: the discovery manifest served at
`/.well-known/gomode.json`, the web-shell contract, the voice gateway transport,
and the scoped-token format. It is the backend counterpart to the Go Mode Android
shell (`android/gomode/`, package `com.fghbuild.gomode`).

caic is the first consumer; mddb is the planned second. See `docs/SERVER_LIBRARY.md` for the boundary and host/adapter split.

**Planned**: extracted to a standalone Go module (`github.com/caic-xyz/gomode`)
once the contract settles. Keep it host-neutral: no caic domain types, no
`backend/internal/*` imports. The contract package (`gomode`) stays stdlib-only;
the transport subpackage (`gomode/voicegateway`) owns the heavy WebRTC deps and
must never be imported by the contract package.

## Layout

- `http.go`, `sdk.go`: discovery manifest types, builder, handler, SDK spec.
- `voicegateway/`: WebRTC voice transport (Gemini Live + local stack), scoped
  tokens, standalone + embedded handlers.

Hosts build a `gomode.Settings` and mount the handler through a thin adapter;
they do not own the wire contract. See `docs/SERVER_LIBRARY.md`,
`docs/ANDROID_SHELL.md`, `docs/VOICE_GATEWAY.md`, and
`docs/IMPLEMENTATION_PLAN.md` for the current architecture and plan.
